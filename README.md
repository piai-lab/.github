# πAI Lab organization defaults

This repository powers the public profile and shared community-health defaults for the πAI Lab GitHub organization.

- [`profile/README.md`](profile/README.md): public organization profile
- [`GOVERNANCE.md`](GOVERNANCE.md): roles and decision-making
- [`PROJECT_POLICY.md`](PROJECT_POLICY.md): project admission and lifecycle
- [`CONTRIBUTING.md`](CONTRIBUTING.md): contribution baseline
- [`SECURITY.md`](SECURITY.md): vulnerability reporting
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md): community standards
- [`SUPPORT.md`](SUPPORT.md): support channels

Individual repositories may add stricter requirements but should not silently weaken these defaults.
